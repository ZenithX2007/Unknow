## Generated Build Artifacts

These directories are generated by ROS 2 / colcon and do not need to be read
when learning the code:

```text
build/
install/
log/
```

They are now listed in `.gitignore`. Do not manually edit files inside them.
If they become stale, rebuild from source:

```bash
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
```

Important: do not delete `install/` in the middle of testing, because terminals
that run `source install/setup.bash` depend on it.

## Python Cache Files

These are generated automatically by Python:


They are safe to ignore. They are now listed in `.gitignore`.
